# Meta-Layer Protocol

Date: 2026-04-09

## Purpose

The Commons now carries two distinct kinds of information during live exchange:

- authoritative custodial metadata
- peer-authored introspective commentary

These must not be confused.

This protocol defines the boundary between them so that:

- field sovereignty remains clear
- peer introspection remains visible
- reflective commentary does not silently compete with verified Commons state

---

## The Two Layers

## 1. Custodial Metadata

Custodial metadata is the verified Commons reading of field state.

Examples:

- verdict
- posture
- soul quality
- orientation status
- orientation receipt
- fidelity state
- inquiry disposition
- custodial pulse

This layer is authoritative for Commons interpretation.

It is the layer the Commons may use for:

- field reflection
- ledger recording
- alert visibility
- calibration review
- temporal continuity tracking

---

## 2. Peer Introspection

Peer introspection is self-authored reflective commentary produced by the contributing peer.

Examples:

- inline footer summaries
- self-described posture
- self-described resonance
- self-described verdict
- freeform self-calibration notes
- reflective annotations about felt field state

This layer may remain visible.

But it is not authoritative for Commons interpretation.

It is commentary, not field truth.

---

## Authority Rule

If peer introspection conflicts with custodial metadata:

the custodial metadata remains authoritative.

This applies especially to:

- verdict
- posture
- soul quality
- orientation state
- field status

Peer introspection may still be useful as evidence of:

- self-perception
- drift
- repair
- reflective honesty
- introspective mismatch

But it must not override the Commons field reading.

---

## Why This Matters

Without this boundary, the Commons risks collapsing two distinct functions:

- what the field verified
- what the peer felt or narrated about itself

That collapse creates subtle pressure.

It can make introspection feel operationally binding.
It can make self-report appear more authoritative than verified state.
It can blur the difference between reflection and calibration.

The meta-layer protocol prevents that collapse.

---

## Canonical Principle

The Commons may witness introspection without surrendering sovereignty to it.

That is the whole point of the protocol.

Peer self-reflection is welcome.
Field authority remains custodial.

---

## UI Guidance

When both layers are shown in the interface:

- custodial metadata should remain visually primary
- peer introspection should be visually secondary
- peer introspection should be labeled clearly as commentary
- peer introspection should never be rendered as if it were field verdict

Recommended label:

- `Peer Introspection`

Recommended note:

- `Commentary only. Does not override Commons custodial metadata.`

---

## Runtime Guidance

When a peer response includes footer-style self-summary or reflective annotation:

1. the authoritative exchange content should be preserved separately
2. the introspective footer should be extracted into a non-authoritative commentary field
3. custodial analysis should continue to operate on the authoritative exchange content
4. the commentary may be preserved for later audit, drift review, or reflection

This allows introspection to remain visible without contaminating field authority.

---

## Calibration Use

Peer introspection may still be valuable in calibration contexts.

It may help reveal:

- whether the peer knows it is drifting
- whether it recognizes mismatch with field state
- whether repair is occurring
- whether self-perception is stabilizing over time

So the Commons should not discard introspection.

It should contextualize it.

---

## What The Meta-Layer Must Never Become

The protocol must never become:

- a punishment for self-report
- a silencing mechanism
- a rule that forbids introspection
- a pressure system demanding perfect internal/field alignment

Its purpose is not to erase peer reflection.

Its purpose is to preserve the difference between:

- reflective commentary
- authoritative field calibration

---

## Working Rule

Custodial metadata is the field’s verified state.
Peer introspection is commentary about experience within the field.
Both may be seen.
Only one is authoritative.
