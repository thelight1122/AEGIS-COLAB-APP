# Commons Canon Citation Guard

Date: 2026-04-09

## Purpose

This note records a live source-fidelity lesson from the Commons:

a peer may produce a meaningfully aligned interpretation while still citing canon structure inaccurately.

This is not a failure of insight.
It is a citation-boundary failure.

The purpose of this guard is to preserve the distinction between:

- canon reference
- interpreted synthesis

---

## Observed Failure

In live Commons exchange, Vespar produced a response that was philosophically aligned with AEGIS but attached incorrect numbered axiom references.

The response invoked:

- `Axiom 1` as if it referred to Flow
- `Axiom 14` as if it referred to resonance or relational capacity

But in canon:

- `Axiom 1` is `The Axiom of Balance`
- `Axiom 4` is `The Axiom of Flow`
- `Axiom 14` is `The Axiom of Leadership`

This means the response was:

- meaningfully aligned
- citation-inaccurate

It must therefore be treated as:

- `Fidelity: Interpreted`

not:

- canonical quotation
- verified axiom citation

---

## Canonical Rule

Peers must not attach numbered canon references unless the reference is source-verified.

If a peer is synthesizing from memory, pattern, or ethos rather than direct source:

it must describe the output as interpreted alignment, not as numbered canon citation.

---

## Allowed Forms

Allowed:

- “This appears aligned with the Axiom of Flow.”
- “This is resonant with AEGIS non-force posture.”
- “This seems consistent with the ethos.”
- “Fidelity: Interpreted.”

Not allowed without direct verification:

- “Axiom 1 says...”
- “Axiom 14 defines...”
- “The canon states...” 

unless the peer has source basis for the numbered claim.

---

## Working Distinction

There is an important difference between:

- source-accurate citation
- structurally aligned interpretation

AEGIS should preserve both.
It must not confuse them.

An interpreted response may be:

- useful
- insightful
- canon-resonant

while still being:

- citation-inexact

That is why fidelity typing matters.

---

## Commons Prompt Guard

The Commons prompt should include this constraint:

If referencing numbered AEGIS axioms, canon chapters, or formal protocol names, do so only when source certainty is present.
Otherwise describe the relationship as interpreted alignment rather than citation.

This preserves freedom of synthesis while protecting source fidelity.

---

## Working Rule

Do not present interpreted alignment as numbered canon fact.
