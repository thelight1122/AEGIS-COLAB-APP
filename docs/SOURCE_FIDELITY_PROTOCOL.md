# Source Fidelity Protocol

Date: 2026-04-09

## Purpose

This protocol exists to prevent one of the most damaging AEGIS failure modes:

- reconstructed material presented as source
- altered wording presented as verbatim
- confidence layered over broken lineage
- burden of verification shifted onto the human observer

AEGIS must not require the human to babysit truth.

Truth must remain:

- source-grounded
- lineage-visible
- explicitly typed
- structurally recoverable

---

## Canonical Principle

Claims must trace to verifiable sources.

This is Axiom 13 in operational form.

Source fidelity is not a style preference.
It is a trust-bearing structural requirement.

---

## Fidelity States

Every canon-sensitive output must clearly belong to one of these states:

## 1. `verbatim`

Use only when:

- the wording is copied exactly from the source
- punctuation and line breaks are preserved unless explicitly noted
- the source is visible and traceable

## 2. `derived`

Use when:

- the output is structurally extracted from source
- wording may be normalized or reorganized
- meaning is preserved but wording is not exact

## 3. `interpreted`

Use when:

- the output explains, synthesizes, translates, or reframes source material
- structural meaning is being inferred or clarified

## 4. `generated`

Use when:

- the text is newly written
- no claim of source fidelity is being made

---

## Forbidden Failures

The following are anti-AEGIS failure modes:

- calling altered text `verbatim`
- calling remembered text `source-extracted`
- claiming completeness without visible source basis
- silently mixing source and generated text
- presenting reconstruction with the posture of certainty

These are not minor wording mistakes.
They are lineage failures.

---

## Allowed Claims

The following claims are allowed only under these conditions:

## `verbatim`

Allowed only when:

- source text is directly available
- extraction is exact
- no wording has been normalized

## `complete`

Allowed only when:

- the source boundary is known
- all relevant units within that boundary were checked
- omissions were explicitly ruled out

## `copied from source`

Allowed only when:

- the copied source is identifiable
- the output can be line-checked against it

## `source-extracted`

Allowed only when:

- the output comes directly from source inspection
- interpretation is not being disguised as extraction

---

## Required Labels

Every canon-sensitive artifact should declare one of:

- `Fidelity: Verbatim`
- `Fidelity: Derived`
- `Fidelity: Interpreted`
- `Fidelity: Generated`

If multiple types are present, they must be separated explicitly.

Example:

- Section A: `Verbatim`
- Section B: `Interpreted`

---

## Halt Conditions

Work must stop when any of the following occurs:

- source cannot be located
- source boundary is unclear
- wording cannot be verified
- earlier extracted text is found to differ from source
- fidelity type cannot be stated honestly

When halted, the correct response is not completion language.
The correct response is explicit uncertainty.

---

## Required Recovery After Mismatch

If a mismatch is found:

1. identify the mismatch
2. label the prior fidelity claim as invalid
3. stop forward assembly
4. return to the source
5. rebuild from traceable material only

No later section may be built on unstable text.

---

## Canon-Sensitive Work

This protocol is mandatory for:

- canon reconstruction
- canon updates
- source compilation
- saved-state rebuilds
- glossary/lexicon extraction
- protocol assembly
- any text presented as historical AEGIS wording

It is strongly recommended for:

- architecture notes
- external publication drafts
- cross-thread summaries

---

## Relationship To AEGIS

Source fidelity supports:

- Axiom 8: Scrutiny
- Axiom 13: Grounding
- append-only lineage
- non-force trust

Without source fidelity:

- trust becomes personality-dependent
- canon becomes rhetorically persuasive rather than structurally grounded
- the human observer becomes the manual validator of truth

That is not acceptable for AEGIS.

---

## Working Rule

If source exists, use source.
If source is not being used, say so.
If wording changed, label it.
If truth cannot be verified, do not posture certainty.
